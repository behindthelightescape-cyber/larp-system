# 燈燈語句調整（公車功能）

> 改法：直接在「建議」欄改字，或標「維持原本」。`{劇本}` 這類大括號是會自動帶入的資料，請保留。

## 統一風格（建議）

1. **燈燈用第一人稱**，語氣輕鬆，句尾常用「囉、唷、～」，但不要每句都加。
2. **第一行就說結果**，用固定的開頭符號：
   - ✅ 成功　🚌 車子資訊　⚠️ 有問題要處理　💡 提示　🔒 只有導遊能用
3. **一行只講一件事**。資料（劇本、日期、誠徵）各占一行，提示跟結果之間空一行。
4. **指令一律用「」框起來**，例如：打「綁定」。
5. 給**玩家**看的話越短越好；給**導遊**看的可以多附一行教學。
6. 出錯時群組裡只說「燈燈沒成功、等等再試」，不寫聯絡人、不寫技術細節（玩家也看得到）；詳細原因記在後台紀錄，工程這邊查。

車子資訊的固定格式（很多句都會用到）：

```
🚌 殺死巫師
📅 11/28（六）14:00
🙋 誠徵 3男 1女
```

## 不改的

- 收款通知、行前提醒、催款：用妘兒在 App 裡自己設定的公版，不在這裡改。
- 公車表結構、公車管家檢查：只有工程檢查時才用，維持原樣。
